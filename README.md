# The Frontier Path — free, from-scratch ML & AI-engineering interview notebooks

> Master the concepts frontier AI labs actually interview on — **transformers & attention, SFT, reward modeling, RLHF, PPO / DPO / GRPO, and LLM agents** — by building each one from scratch in PyTorch. One concept a day. Free + MIT.

**Who it's for:** anyone prepping for an ML / AI-engineering / LLM interview, or leveling up on post-training and agents by implementing them from scratch instead of just reading about them.

**17 / 24 notebooks live.** New ones unlock in curriculum order as the daily [@mootvstherubric](https://www.instagram.com/mootvstherubric) Frontier Path reaches them (schedule below).

⭐ **Star the repo** if it helps — that's how other people prepping for the same interviews find it.

## Run a notebook (free)
- **Colab:** open any ✅ notebook below and click *Open in Colab* — no setup, free GPU.
- **Local:** `git clone` this repo → `pip install torch transformers trl datasets accelerate peft` → `jupyter lab`.
